# Battery Price Monitor

A daily price and news monitor for the LFP battery supply chain: lithium, LFP cathode, storage cells (314 Ah and 587 Ah), packs and storage systems, plus other raw materials and the week's top news. All prices in US$, each with a link to its public source.

- Live page: https://kaniket796.github.io/battery-monitor/
- Data: `data/*.json` (the page reads only these files)
- How it is updated: see `UPDATING.md`

Compiled from public sources for internal information only. Check the original source before relying on a figure.
