# Leyland Pulse

Leyland Pulse is a daily battery market intelligence page for the LFP battery supply chain: lithium, LFP cathode, storage cells (314 Ah and 587 Ah), packs and storage systems, plus other raw materials and news on cell makers, packs and BMS, R&D and new products, energy storage, EVs, Indian storage and EV/battery makers, and regulation. All prices in US$, each with a link to its public source.

- Live page: https://kaniket796.github.io/battery-monitor/
- Data: `data/*.json` (the page reads only these files)
- Tabs: Overview · Raw materials (every price, plus lithium, cell and storage-system charts) · News · Cost calculator (builds cell and system cost from raw-material prices; scenarios can be shared by link)
- How it is updated: see `UPDATING.md`

Compiled from public sources for internal information only.
