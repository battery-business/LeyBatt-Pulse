                  Market notes

                    Method: prices come from the public sources linked on each item and are converted to US$ at a fixed US$1 = 6.70 yuan; older dates use the same rate, so they are approximate. China cell and system prices include 13% VAT, which is removed so they compare with international prices. Pack prices come from BloombergNEF's annual survey (December 2025). Iron phosphate, graphite and foil prices have no free weekly source, so the latest public figures are used and dated.

                    Automatic updates: this website updates itself every day at 4:00 am IST. Chinese markets open later, so each morning shows the previous trading day’s prices; weekend updates mainly add news.
